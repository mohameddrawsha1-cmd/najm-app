# بوابة تقنية المعلومات — PHP / MySQL

نظام عربي RTL لإدارة أعطال وطلبات تقنية المعلومات والخدمات الداخلية. الواجهة مستوحاة من هوية نجم الداكنة بالأسود والذهبي، مع بنية MVC خفيفة وواضحة تعمل على PHP 8.2 وMySQL 8.

## ما الذي يتضمنه المشروع؟

- تسجيل دخول آمن، جلسات، CSRF، قفل مؤقت بعد المحاولات الفاشلة، وتشفير كلمات المرور.
- أدوار مدير النظام، مشرف الدعم، فني الدعم، موظف، مدقق، وأدوار العملاء والمزودين الجاهزة للتوسع.
- تذاكر للأعطال، طلبات الخدمة، الموظف الجديد، الاستقالة، والطلبات العامة.
- تصنيفات للكمبيوتر، الإنترنت، الشبكة، الإيميل، الطابعة، إنشاء حساب، البرامج، الكهرباء، والخدمات الداخلية.
- حالات وأولويات، إسناد للفنيين، رسائل عامة، ملاحظات داخلية، سجل تغييرات، ومواعيد استحقاق.
- سجل مستخدمين وأجهزة ومواقع وأقسام ومزودي خدمة.
- قوائم تنفيذ تلقائية للتوظيف والاستقالة وتجهيز جهاز جديد.
- تقارير حسب الحالة والتصنيف وتصدير CSV.
- سجل تدقيق، إشعارات، حقول ديناميكية، مرفقات، رموز استعادة، وإعدادات نظام في قاعدة البيانات.
- تصميم متجاوب للكمبيوتر والهاتف.

## المتطلبات

- PHP 8.2 أو أحدث مع pdo_mysql وmbstring وjson
- MySQL 8.0 أو أحدث
- Apache مع mod_rewrite أو خادم PHP المدمج
- Composer اختياري، فالمشروع يحتوي محمّلًا تلقائيًا احتياطيًا

## التشغيل السريع محليًا

1. انسخ الملف .env.example إلى .env.
2. عدّل بيانات قاعدة البيانات في .env.
3. استورد database/database.sql.
4. أنشئ أول مدير بالأمر: php scripts/create-admin.php
5. شغّل التطبيق: php -S 127.0.0.1:8000 -t public
6. افتح http://127.0.0.1:8000

## التشغيل بـ Docker

شغّل: docker compose up --build

بعد أن تصبح MySQL جاهزة شغّل:
docker compose exec app php scripts/create-admin.php

ثم افتح http://localhost:8080

## بنية المجلدات

~~~text
app/
  Config/          إعدادات التطبيق
  Controllers/     استقبال الطلبات والتحقق والتوجيه
  Core/            قاعدة البيانات والجلسات وCSRF والتوجيه والعرض
  Repositories/    استعلامات وحركات البيانات
  Views/           واجهات عربية RTL
database/
  database.sql     المخطط الكامل والبيانات الأساسية
docs/
  ARCHITECTURE.md  شرح البنية والقرارات الأمنية
public/
  assets/          CSS وJavaScript
  index.php        نقطة دخول الويب الوحيدة
routes/
  web.php          مسارات النظام
scripts/
  create-admin.php إنشاء أول مدير بأمان
storage/
  logs/ uploads/   ملفات تشغيل غير عامة
tests/
  smoke.php        فحوصات المشروع الأساسية
~~~

## الأمان قبل الإنتاج

- اجعل APP_DEBUG=false.
- استخدم HTTPS ومستخدم MySQL محدود الصلاحيات.
- وجّه Document Root إلى مجلد public فقط.
- امنع تنفيذ الملفات داخل storage/uploads وافحص المرفقات.
- خزّن النسخ الاحتياطية خارج خادم التطبيق.
- لا تضف .env أو كلمات المرور إلى Git.
- راجع مدد الاحتفاظ بالتذاكر وسجلات التدقيق وبيانات الاستقالة.
- أنشئ مهامًا مجدولة للتنبيهات والتنظيف عند تفعيلها.
